# Verify Scanner Test Repository

This is a disposable, intentionally vulnerable fixture repository for validating
the Verify GitHub scanner.

IMPORTANT:
- Every credential-looking value is fake and non-functional.
- Do not use any value from this repository as a real credential.
- Delete this repository after testing if you no longer need it.

Expected scanner coverage:
1. SecretAnalyzer
2. ConfigAnalyzer
3. DependencyAnalyzer
4. SourceAnalyzer
